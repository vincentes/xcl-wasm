`299140fafd08df55a9c234e610c3f64af3f45531` (SKILL.md 1.1.1). `src/XclDemo.tsx` is built on it.

some under Apache-2.0, which XCL cannot carry), and their exports are removed from `index.ts`,
`parts/index.ts` and `stageshow.css`. Nothing else is edited: update by copying the kit again and
repeating that removal, not by changing files here.
